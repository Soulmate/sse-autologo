# SSE Glass Logo

Однофайловый инструмент: накладывает логотип SSE и слоган в стиле «жидкого стекла» (как цифры часов на локскрине iOS 26) поверх любой картинки и экспортирует PNG нужного размера. Например, для фонов видеозвонков, обложек и постов в LinkedIn.

Всё в одном файле [`index.html`](index.html): без сборки и сервера, работает офлайн. Логотип и шрифт Inter Light вшиты внутрь.

## Как пользоваться

1. Откройте `index.html` двойным кликом или через GitHub Pages.
2. Перетащите в окно JSON с настройками (или «Открыть JSON…»).
3. Перетащите картинку (или «Открыть…» / Ctrl+V).
4. Нажмите «Экспорт PNG».

Все параметры (кадр, лого, текст и шрифт, стекло, свет, тень) открываются кнопкой «Все настройки». Там же можно сохранить текущие настройки в JSON. Последние настройки автоматически сохраняются в браузере.

## Версия настроек

Текущая версия JSON: **`version: 1`**.

Загружаются только файлы с текущей версией. Файл другой версии или без поля `version` будет отклонён. Автоматической миграции нет: старые файлы конвертируются вручную по списку изменений ниже. При любом несовместимом изменении схемы нужно поднять `SETTINGS_VERSION` в `index.html` и добавить запись в список.

### Схема v1

Размеры стекла и тени заданы в % от высоты лого. У текста они масштабируются от кегля. Поэтому вид не зависит от разрешения.

```jsonc
{
  "version": 1,
  "out":   { "w": 1920, "h": 1080 },              // выходное разрешение, px (16…8192)
  "crop":  { "zoom": 1, "px": 50, "py": 50 },     // зум ×1…×5 от cover; положение 0…100 % от свободного хода
  "logo":  { "x": 4.31, "y": 35.07,               // левый верхний угол лого, % ширины / высоты кадра
             "width": 38.28,                      // ширина лого, % ширины кадра
             "opacity": 1,                        // прозрачность всего слоя лого 0…1
             "glass": true,                       // false — без стекла: заливка "flat" + opacity
             "flat": "#ffffff",                   // цвет заливки без стекла
             "top": "#d6d9ea", "bot": "#9da3bd" },// градиент стекла
  "text":  { "on": true,
             "content": "YOUR PARTNER FOR TIME CRITICAL SHIPMENTS",
             "mode": "under",                     // "under" — под лого на всю его ширину, "free" — свободно
             "size": 18.15,                       // кегль, % высоты лого
             "spacing": 0.46,                     // межбуквенный, em (только "free")
             "gap": 40.6,                         // отступ от низа лого до верха заглавных, % высоты лого ("under")
             "x": 4.31, "y": 54,                  // левый край / базовая линия, % кадра ("free")
             "density": 0.69,                     // плотность заливки стекла текста 0…1
             "opacity": 1,                        // прозрачность всего слоя текста 0…1
             "glass": true, "flat": "#ffffff",    // как у лого
             "ownColor": false, "top": "#d6d9ea", "bot": "#9da3bd", // свой градиент (иначе как у лого)
             "font": { "kind": "builtin",         // "builtin" (Inter Light) | "system" (по имени) | "file" (вшит)
                       "family": "Inter Light",   // имя системного шрифта / подпись загруженного
                       "weight": 300,             // 100…900, только для "system"
                       "data": "" } },            // data:font/...;base64 для "file", иначе ""
  "glass": { "density": 0.44,                     // плотность заливки лого 0…1
             "frost": 2.59,                       // размытие фона под стеклом, %
             "rimKey": 0.9, "rimWidth": 1.38,     // верхний блик: яркость 0…1, толщина %
             "shade": 0.45, "shadeColor": "#1b2140", // нижняя тёмная кромка
             "bump": 3.02,                        // мягкость бевела (blur bump), %
             "surface": 4.32,                     // surfaceScale, %
             "sheen": 0.35 },                     // сила бевел-блика
  "light1": { "az": 235, "el": 40, "k": 0.9, "color": "#ffffff", "exp": 18 }, // ключевой свет
  "light2": { "az": 45,  "el": 30, "k": 0.5, "color": "#8fdcff", "exp": 14 }, // заполняющий свет
  "shadow": { "blur": 4.32, "dy": 4.32, "opacity": 0.55, "color": "#000812" },
  "exportName": ""                                // имя PNG; пусто — glass-logo_<W>x<H>.png
}
```

Сама картинка в JSON не входит.

## История версий настроек

| Версия | Изменения | Как конвертировать из предыдущей |
|---|---|---|
| 1 | Первая версионированная схема. Добавлены `version`, `logo.opacity`, `text.opacity`, `logo.glass`, `logo.flat`, `text.glass`, `text.flat`. | Из файлов без версии: добавить `"version": 1`. Новые поля можно не указывать, подставятся значения по умолчанию (`opacity: 1`, `glass: true`, `flat: "#ffffff"`). |
